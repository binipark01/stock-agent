# KRX Telegram alerts

운영용 KRX 텔레그램 알림 스크립트 복사본이다.

## 구성

- `regular.py`: 정규장 알림 본문 생성
- `afterhours.py`: 장후/SOR 알림 본문 생성
- `regular_review.py`: 정규장 LLM 검수 패킷 생성
- `afterhours_review.py`: 장후/SOR LLM 검수 패킷 생성 및 20:05 이후/주말 무음 처리
- `review_common.py`: LLM 검수 공통 패킷/진단 로직
- `jobs.example.json`: 비밀값 제거한 cron 예시

## 운영 스케줄

- 정규장: 평일 08:00~15:55, 5분마다
- 장후/SOR: 평일 16:00~20:00, 5분마다
- 주말은 발송하지 않는다.
- 장후/SOR cron 표현식은 20시 전체를 포함하지만 스크립트에서 20:05 이후는 `wakeAgent: false`로 차단한다.

## 출력 원칙

- 현재가와 등락률을 함께 표시한다.
- 테마 블록 사이에는 빈 줄을 둔다.
- 큰 테마의 주도주에만 수급/이슈 상세를 붙이고, 세부 테마는 요약 목록으로 둔다.
- 이슈는 LLM 검수 단계에서 후보 뉴스를 다시 판단한다.
- 의미 없는 이슈는 `관련 종목뉴스 확인불가`로 둔다.
- 말줄임표나 중략 표기는 출력하지 않는다.
