- 저점권/발바닥: 이미 많이 빠진 종목에서 하락 둔화와 바닥권 구조를 찾는다.
- 매집/큰손: 차트상 누적 매집이 끝나가고 중장기 추세 전환 초입인 구간을 선호한다.
- 지지선: 지지 가격을 명시하고, 그 가격을 지키는지가 setup 유효성의 핵심이다.
- 손익비: 그냥 좋아 보이는 종목보다 손익비 타점이 나오는 가격대를 중시한다.
- 시간축: 단타, 단기 스윙, 단기~중기 스윙, 중장기 추세전환을 구분한다.
- 태도: 맹신 금지, 직접 판단, 시간을 두고 검증, 차분한 대응을 강조한다.

## agent 규칙

1. `jtdj_chartist_requires_krx_quote`
   - 한국 티커와 원화 가격대가 나오면 KRX 심볼로 변환하고 현재가와 거리부터 계산한다.

2. `jtdj_support_invalidation_first`
   - “지지가 있고 지키면”, “손익비 타점” 문구가 있으면 해당 가격을 setup activation/invalidation 구간으로 저장한다.

3. `jtdj_accumulation_needs_volume_confirm`
   - 매집/큰손/발바닥은 사실이 아니라 차트 해석이다. 거래량·가격구조 확인 전까지 확정 표현 금지.

4. `jtdj_horizon_separation`
   - 단타/단기/중기/중장기 시간축을 그대로 보존한다. 단타 글을 장투 thesis처럼 쓰지 않는다.

5. `jtdj_no_standalone_buy_alert`
   - jtdj 관점은 매수 추천이 아니라 persona chart view로만 표시한다. 별도 검증과 리스크를 붙인다.

6. `jtdj_reposts_not_author_claims`
   - 리포스트/팔로워 댓글은 crowd context로만 쓰고, 작성자 직접 claim으로 저장하지 않는다.
